## Purpose

The purpose of this section is to fully document the database structure of the application so that it can be easily understood without needing to review the source code. It provides a complete overview of all tables, their columns, data types, and relationships between entities.

This documentation ensures that a future developer can understand how data is stored, how different parts of the system are connected, and what each field represents. It also helps maintain consistency, supports future development, and reduces the risk of errors when modifying or extending the database.
