# Escalation Path

If a critical issue cannot be resolved using the runbook alone, contact the people listed below.

A critical issue may include:

- The production website is unavailable
- Students or teachers cannot log in
- Data cannot be loaded or saved
- Reports cannot be generated
- The database backup or restore process fails
- Repeated application errors appear in the logs

## Information to Include When Escalating

When reporting a critical issue, include:

- Your name
- Date and time of the issue
- Which part of the system is affected
- Production URL used
- Screenshot of the error
- Steps already attempted
- Any related log entries
- Whether the issue affects one user or all users
