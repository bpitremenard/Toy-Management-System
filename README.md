# Development Project — Toy Management System

## Course
Development Project I and II

## Description
The Toy Management System is a full-stack application built for the ECCE department to manage toy inventory and student borrowing. The project includes separate Teacher and Student web applications connected through a shared API.

Teachers can manage toys, students, images, and system data. Students can browse available toys and borrow them through the student portal. The project also included testing, documentation, CI/CD pipeline work, user documentation, and a system runbook.
